Axion SPK Analyzer

Browser tools for Axion BioSystems spike files (.spk, from AxIS / AxIS Navigator on Maestro systems).

MEA pipeline

Activity replay, plate map, raster, waveforms, firing statistics and network bursts, with every definition written out in its info box.

Files are read in your browser and never uploaded. Python versions of the analyses and the verification scripts are in the repository.
